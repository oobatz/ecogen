# ECOGEN

Образовательная 2D-игра о восстановлении города: сортировка, переработка, озеленение и экологичная энергия.
Браузерная, горизонтальный экран, телефон (iPhone) и компьютер. Без сборки и зависимостей.

## Запуск
Нужен любой статический веб-сервер (из-за шрифтов и локального хранилища лучше не открывать файл напрямую):

```bash
cd C:/Game && python -m http.server 8765
```

Затем откройте http://127.0.0.1:8765/. Для iPhone выложите папку на любой статический хостинг
(GitHub Pages, Netlify и т. п.) и откройте ссылку в Safari; «На экран Домой» — полноэкранный режим.

## Что есть в версии 0.1
- Стартовый экран, новая игра (ник), выбор одного из 4 персонажей, вступительная история.
- Карта единого города из 9 районов; стартовый район меняется по мере игры
  (мусор исчезает, земля зеленеет, дома ремонтируются, предметы появляются на карте, дым фабрики слабеет).
- Глава I (уровни 1–10) полностью играбельна; уровни 11–50 описаны и видны в списке заданий.
- Монеты, энергия, научные очки, опыт; награда за уровень = номер × 100.
- Лаборатория (исследования + бонусные исследования за научные очки), магазин с размещением предметов.
- Мини-игры: сортировка мусора, лабораторный анализ, энергия из органики (биогаз), энергосеть.
- Достижения, профиль, настройки, автосохранение, перенос сохранения кодом.

## Структура
- `js/data/` — данные: персонажи, карта, магазин, исследования и отходы, история и диалоги, уровни.
  Новые задания, предметы, цены и районы добавляются здесь, без правки логики.
- `js/core/` — состояние и сохранение, движок заданий.
- `js/ui/` — графика (SVG), карта, интерфейс.
- `js/games/` — мини-игры.
- `DESIGN.md` — исправленные решения к концепции (что было неясно и как закрыто).

## Как добавить уровень
В `js/data/levels.js` замените строки задач уровня на объекты с `type`
(`dialog`, `tap`, `research`, `minigame`, `buy`, `place`, `collect`, `clearAll`, `deliver`, `earn`, `restore`).
Уровень станет играбельным автоматически.
